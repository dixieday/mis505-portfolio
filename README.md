# MIS 505 Final Portfolio Project

Analysis of primary education enrollment and GDP per capita in Australia, 2001-2020.

- australia_primary_enrollment_gdp.csv - the cleaned dataset (20 rows)
- australia_education_gdp.db - SQLite database containing the same data
- australia_data_dictionary.json - description of the dataset's columns

Data source: World Bank World Development Indicators. The dataset was built in a Jupyter notebook by cleaning and merging the enrollment and GDP files.
